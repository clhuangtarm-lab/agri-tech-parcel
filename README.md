# 來自田間的神奇包裹

把田裡的科技投遞到生活中。農糧農環科技成果特展的互動網站：送貨車、開門、在餐桌上拆開五個小包裹，展開 64 項農業技術。

- 單一頁面，使用 Three.js 0.160.0（由 cdn.jsdelivr.net 載入），沒有建置步驟。
- `index.html`：主程式；`data/`：64 案資料；`media/`：卡片用照片。
- 本機預覽：在此資料夾執行 `python -m http.server 8765`，開啟 http://localhost:8765/

## 資料與圖片來源

- 展覽規劃、五區分類與 64 案名單：農糧農環科技成果特展規劃簡報。
- 05 多元應用區（第 59、61–64 案）的內容改寫自各機關公開頁面，網站卡片的「資料來源」可展開查看連結與查閱日期。
- 照片取自農業部桃園區農業改良場（2026-03-27 新聞稿）與農業部茶及飲料作物改良場（2020 年新聞稿、橙茶新聞稿），依各機關「網站資料開放宣告」須註明出處；專利、商標、機關標誌不在授權範圍。
- 其餘 4 區的技術故事尚在整理中。
